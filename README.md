# Visulaser

ILDA laser show editor — Phase 1 prototype (vector editor: shapes, RGB, transform, scenes, save/load). See project vision in the original cahier des charges.

## Development

```bash
npm install
npm run dev          # web app at http://localhost:5173
npm run electron:dev # same app in an Electron window
```

## Build a Windows executable

```bash
npm run dist:win
```

Produces `dist/win-unpacked/Visulaser.exe`.
